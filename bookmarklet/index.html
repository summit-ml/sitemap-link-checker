Sitemap Link Checker

This is the no-install version of Sitemap Link Checker. It checks every link in a sitemap and tells you which ones open a real page, which redirect, and which land on a not-found or error page. It runs inside your own browser, on the site you are testing, so it uses the login you already have.

Step 1: add the button to your browser (once)

Show the bookmarks bar (Cmd + Shift + B in Chrome, View > Show Favorites Bar in Safari), then drag this button onto it:

Check Sitemap Links

Dragging not working?
Then open the site, press Cmd + Option + J (Chrome) to open the Console, paste, and press Return.

Step 2: run it

  1. Open the site you want to test, for example its home page. Enter the storefront password if you are asked.
  2. Click Check Sitemap Links in your bookmarks bar. A panel opens over the page.
  3. The sitemap address is filled in for you. Click Load sitemap, tick the sitemap files you want, then click Check links.
  4. When it finishes, use the filter buttons to see only the problems, and Download CSV to save the results.

You can also paste a list of links, one per line, instead of loading a sitemap.

What the results mean

ResultMeaning
OKThe link opened a normal page.
RedirectThe link sent you to a different address. The final address is shown.
Redirect to homeThe link sent you to the home page, which usually means the product or category is no longer available.
Not foundThe site answered "not found", or the page shows one of the not-found messages.
No resultsThe link opened a search or category page that lists no products.
ErrorThe site returned an error page, or the link could not be loaded at all.

Good to know

  • Run it on the same site as the sitemap. A browser only lets a page check links on its own site. Links to a different site are listed as "Skipped".
  • Not-found messages are a list you can edit. Some pages load normally but only say "we can't find that". The checker looks for those phrases in the page text. If it misses one, add the wording to the list in the panel and run again. Each flagged row shows the phrase that matched.
  • It is gentle on the site: three links at a time. A few hundred links take a few minutes.
  • Nothing is installed and nothing is sent anywhere. Reloading the page removes the panel.
